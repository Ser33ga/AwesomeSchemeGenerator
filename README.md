# Генератор блок-схем

На вход подаётся JSON в UTF-8; программа создаёт SVG и PNG. Браузер не нужен.

## Требования

- Python 3.10+
- Для режима `auto`: Graphviz (`dot` должен быть доступен в PATH).
- Для режима `manual`: `pip install pillow cairosvg`; библиотека CairoSVG также требует системную библиотеку Cairo. Для SVG используется установленный шрифт `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` (при другом расположении измени `font_path` в скрипте).

## Запуск

```bash
python flowchart.py auto_example.json
python flowchart.py manual_example.json -o result
```

В первом случае создаются `auto_example.svg` и `auto_example.png`, во втором — `result.svg` и `result.png`.

## Структура JSON

Корневой объект содержит строго `mode`, `nodes`, `edges`. `mode` — `auto` или `manual`.

- Каждый блок: `id` (уникальный ID из латинских букв, цифр, `_` и `-`, первая — буква или `_`), `type`, `text`.
- Типы: `start`, `end` (овалы со скругленными концами), `process` (строгий прямоугольник с прямыми углами 90°, без скруглений), `decision` (ромб), `input_output` (параллелограмм).
- В `manual` каждый блок дополнительно содержит `position: {"x": 200, "y": 100}`. Это координаты **центра блока в пикселях**: X вправо, Y вниз. В `auto` поле `position` запрещено.
- Каждая связь: `from`, `to`; необязательные поля `label`, `from_port`, `to_port`, а также `points` (только для `manual`) — список промежуточных точек изгиба стрелки, например `[{"x": 670, "y": 540}, {"x": 670, "y": 380}]` или `[[670, 540], [670, 380]]`. Порты: `n`, `s`, `e`, `w`, `ne`, `nw`, `se`, `sw`.
- Пример обеих схем — в `auto_example.json` и `manual_example.json`.

Размер блоков подстраивается под текст; длинный текст переносится. Режим `manual` является предпочтительным по умолчанию для создания чистых и аккуратных схем без паразитных изломов и обходов блоков: координаты центров соблюдаются точно, а стрелки направляются по заданным портам. В `auto` раскладку и маршруты стрелок рассчитывает Graphviz. Смешанного режима нет.

Ошибки структуры выводятся в терминал с ненулевым кодом завершения. Для ИИ удобно давать оба примера JSON и требовать только JSON без Markdown-обёртки.
