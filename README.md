# Генератор блок-схем

На вход подаётся JSON в UTF-8; программа создаёт исходник для draw.io (`.drawio`), а также векторное (`.svg`) и растровое (`.png`) изображения.

Файл `.drawio` открывается напрямую в редакторе [draw.io (diagrams.net)](https://app.diagrams.net/): все блоки и стрелки полностью интерактивны и редактируемы. Кроме того, исходник вшит прямо в сгенерированный `.svg`, поэтому перетаскивание `.svg` в draw.io также открывает схему для редактирования.

## Требования

- Python 3.10+
- Для режима `auto`: Graphviz (`dot` должен быть доступен в PATH).
- Для режима `manual`: `pip install pillow cairosvg`; библиотека CairoSVG также требует системную библиотеку Cairo. Используется системный шрифт Arial.

## Запуск

```bash
python flowchart.py auto_example.json
python flowchart.py manual_example.json -o result
```

В первом случае создаются `auto_example.drawio`, `auto_example.svg` и `auto_example.png`, во втором — `result.drawio`, `result.svg` и `result.png`.

## Структура JSON

Корневой объект содержит строго `mode`, `nodes`, `edges`. `mode` — `auto` или `manual`.

- Каждый блок: `id` (уникальный ID из латинских букв, цифр, `_` и `-`, первая — буква или `_`), `type`, `text`.
- Типы: `start`, `end` (овалы / блоки со скругленными концами), `process` (строгий прямоугольник с прямыми углами 90°, без скруглений), `decision` (ромб), `input_output` (параллелограмм).
- В `manual` каждый блок дополнительно содержит `position: {"x": 200, "y": 100}`. Это координаты **центра блока в пикселях**: X вправо, Y вниз. В `auto` поле `position` запрещено.
- Каждая связь: `from`, `to`; необязательные поля `label`, `from_port`, `to_port`, а также `points` (только для `manual`) — список промежуточных точек изгиба стрелки, например `[{"x": 670, "y": 540}, {"x": 670, "y": 380}]` или `[[670, 540], [670, 380]]`. Порты: `n`, `s`, `e`, `w`, `ne`, `nw`, `se`, `sw`.
- Пример обеих схем — в `auto_example.json` и `manual_example.json`.

Размер блоков подстраивается под текст; длинный текст переносится. Режим `manual` является предпочтительным по умолчанию для создания чистых и аккуратных схем без паразитных изломов и обходов блоков: координаты центров соблюдаются точно, а стрелки направляются по заданным портам. В `auto` раскладку и маршруты стрелок рассчитывает Graphviz.
